# FlowForge web-app

![CI](https://github.com/My-second-free-organization/web-app/actions/workflows/ci.yml/badge.svg)

React 18 TypeScript SPA for managing workflows, tasks, and analytics.

## Tech Stack
- React 18 + TypeScript
- Vite, TailwindCSS, React Query
- Zustand for state management

## Quick Start
```bash
npm install && npm run dev
```
